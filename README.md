# Ganadería Toné · Propuesta de sociedad

**Criamos calidad, proyectamos genética.**

Presentación del proyecto para abrir en sociedad una sucursal de Ganadería Toné en una zona central, cerca de Medellín, para ampliar la venta y la visibilidad de nuestra genética Gyr y Gyrolando.

## Cómo verla

- **En línea:** https://jadersondavid.github.io/ganaderia-tone/
- **En el computador:** abrir `index.html` con el navegador.

**Controles:** flechas ← → o deslizar con el dedo · `F` pantalla completa · `Ctrl + P` para guardar en PDF.

## Contenido

1. Portada
2. La propuesta: sucursal en sociedad
3. La raza: todo empieza en una buena vaca Gyr
4. El proyecto como una casa: lechería, genética y terneril
5. Cifras de mercado
6. Escalera de valor de la genética
7. El terneril, la joya de la corona
8. La lechería: datos y plata
9. Simulador de ventas (interactivo)
10. La sociedad: lo que aporta el socio (tierra y núcleo genético Gyr de élite)
11. Nuestras campeonas: Pandora (Agroexpo) y Duquesa (Expogirardota)
12. Galería
13. Cierre y contacto
